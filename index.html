05 / ROADMAP

LA SUITE AZOX

Le prototype est prêt pour les essais locaux. La prochaine étape sera de relier le site à une base de données partagée.

ÉTAPE 01

Valider les données

Compléter les profils avec les pseudos, rôles et présentations confirmés par Rome, Lucky et Sacha.

ÉTAPE 02

Créer la base

Le dossier contient un script SQL Supabase pour les joueurs, les résultats et le classement calculé.

ÉTAPE 03

Mettre en ligne

Héberger le site statique, puis connecter l’affichage public à Supabase avec des droits d’administration sécurisés.

IMPORTANT POUR LA VERSION PUBLIQUE
Ne place jamais une clé secrète Supabase dans le HTML. Le site public doit utiliser uniquement une clé publique anon avec les règles RLS activées. Les écritures doivent être réservées aux comptes administrateurs autorisés. Le script SQL fourni prépare cette séparation.
